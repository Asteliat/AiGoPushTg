# Ревизия AtcivPerson — 2026-11-04

## Объём

Проверены дерево репозитория, точки запуска Docker Compose, основное меню и callback-маршруты бота, связанные Telegram Gateway операции, основной Worker, фоновые задачи, модели БД, тесты и пользовательская документация.

## Удалено

### Старый недоступный UI и его обработчики
- Удалён старый раздел tool:management и вложенные callback-маршруты tool:mg.
- Удалены старые универсальные модули MODULE_ACTIONS и tool:module:*, tool:policy:*, tool:quarantine:*.
- Удалены настройки парсера и обработчики экспорта/сбора участников.
- Удалены старые обработчики контактов, пакетных подписок и отписок, рассылок/приглашений, реакций, расписаний кампаний, очередей и журналов этих модулей.
- Удалены обработчики загрузки файлов и подтверждения кампаний, которые относились только к старым инструментам.
- Удалены неиспользуемая запись журнала контактов и устаревшие маршруты восстановления экранов старых инструментов.

### Backend и фоновые процессы
- Удалены неиспользуемые методы Telegram Gateway: контакты, парсинг истории/комментариев/участников, пакетные подписки, реакции, старые операции вступления/выхода, старые резолверы групп и получателей, обзор чата и список диалогов для парсера.
- Удалён сервис очереди кампаний и реакций app/services/automation.py.
- Удалён отдельный worker-диспетчер app/workers/automation.py и его запуск из app/workers/main.py.
- Удалён тестовый набор старого automation-сервиса и тесты удалённых Telegram Gateway операций.
- Удалены docs/ACCOUNT_TOOLS.md и неиспользуемый app/bot/handlers.py, который только повторно экспортировал router из app.bot.ui.

## Сохранено намеренно

- Управление аккаунтами, QR/телефонный вход, прокси и изолированные сессии.
- Настройка профиля: имя, фамилия, BIO, username, фото и публикация истории.
- Статический автоответчик. Его настройки добавлены в активный экран настройки аккаунтов; Worker продолжает применять правило «только личные сообщения и только когда ИИ аккаунта выключен».
- Ручная отправка сообщения с предварительным просмотром и подтверждением.
- Поиск групп и каналов, проверка найденных ссылок и вступление только после подтверждения.
- Чаты, AI-агенты, персоны, примеры, триггеры, автообучение, учебные задания, канальный мониторинг, анализ публикаций, уведомления и маршрутизация логов.
- API и отдельные CLI-команды администрирования Telegram-сессий.

## Совместимость БД

ORM-классы AutomationTask, AutomationTaskRecipient, AutomationSchedule, ScheduledReaction, AutomationConsent, AutomationInviteConsent и AutomationOperationEvent сохранены намеренно. Они описывают существующие таблицы и данные PostgreSQL. Исполнитель старых задач больше не запускается, но сама очистка не удаляет таблицы, строки, файлы сессий или данные пользователей. Отдельная destructive-миграция не создавалась.

## Ограничения проверки

CI (Ruff и pytest) должен быть запущен для этой ветки и проверен до слияния. После CI нужен серверный smoke-тест: запуск bot/worker, вход аккаунта, работа поиска групп/каналов, обновление профиля, AI/триггеры, обучение и уведомления. Сервер не обновлялся.
