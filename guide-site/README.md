# AtcivPerson Guide

Отдельный интерактивный статический сайт. Он имитирует структуру меню Telegram-бота AtcivPerson: посетитель нажимает кнопки, открывает вложенные экраны и читает подробное описание каждой функции. Сайт не подключается к Telegram, API или базе данных и не может менять настройки бота.

## Локальный просмотр

```bash
cd guide-site
python3 -m http.server 8088
```

Откройте `http://127.0.0.1:8088`.

## Публикация на guide.cloudre.store

1. Создайте DNS A-запись:
   - Host: `guide`
   - Type: `A`
   - Value: `177.3.219.102`
2. Убедитесь, что входящие TCP-порты 80 и 443 доступны снаружи и свободны на сервере.
3. Скопируйте каталог `guide-site` на сервер.
4. Из этого каталога выполните:

```bash
docker compose up -d
docker compose ps
docker compose logs --tail=100 guide
```

Caddy автоматически запросит и обновит TLS-сертификат для `guide.cloudre.store`. DNS-запись должна уже указывать на этот сервер, а порты 80/443 должны быть доступны из интернета.

> Важно: этот compose-файл поднимает собственный Caddy и занимает порты 80/443. Если на сервере уже работает другой веб-сервер или Caddy, не запускайте второй экземпляр с теми же портами. В таком случае используйте `Caddyfile` как отдельный site block в уже работающем Caddy и направьте `root` на каталог сайта.

## Файлы

- `index.html` — интерактивное меню-руководство, поиск по функциям и адаптивный интерфейс.
- `Caddyfile` — HTTPS и статическая раздача сайта на `guide.cloudre.store`.
- `docker-compose.yml` — автономный Caddy для выделенного сервера.
